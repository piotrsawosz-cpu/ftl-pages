# ftl-pages

Hosted code for FTL UTD GoHighLevel landing pages. Each GHL page has a 2-line loader (`<div id="ffl-mount">` + `<script src=".../<campaign>/<channel>.js">`) that pulls its page from here.

Generated by `program-page-kit/make_hosted.py` in the FTL UTD workspace. Do not hand-edit; rebuild and push instead.
